What to write on the NFC tag

Always store a secure URL, not the medical data directly on the chip.

Supabase

Suggested database structure

Add a medical profile table and a new target type for medical NFC tags. 

create table public.medical_profiles (
  id uuid primary key default gen_random_uuid(),
  company_id uuid,
  full_name text,
  conditions text,
  allergies text,
  medications text,
  devices text,
  blood_type text,
  doctor text,
  clinic text,
  emergency_contact_1 text,
  emergency_contact_2 text,
  notes text,
  is_public boolean default true,
  created_at timestamptz default now()
);
nfc_tags.target_type 'medical'

Operational flow

Simple workflow from product to scan

  1. Print a medical bracelet, card, or keychain.
  2. Insert the NFC chip.
  3. Write the secure profile URL.
  4. User scans the tag with their phone.
  5. The web app reads Supabase and shows the profile.
  6. Log the event for analytics or traceability.
